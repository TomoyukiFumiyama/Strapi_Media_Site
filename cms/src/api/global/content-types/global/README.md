# global ディレクトリ README

## ディレクトリの役割
`global` content-type の最終スキーマ定義を配置するディレクトリです。

## 配下ファイルと役割
- `schema.json`: `global` の Single Type スキーマ定義。API 経由で管理するフィールドとリレーションの制約を定義します。主な属性: site_name, default_seo, header_cta, footer_cta, company_name, company_address, company_tel, og_default_image。

## 運用メモ
- 新しいファイルを追加したら、この README の「配下ファイルと役割」を更新してください。
