# office ディレクトリ README

## ディレクトリの役割
`office` content-type の最終スキーマ定義を配置するディレクトリです。

## 配下ファイルと役割
- `schema.json`: `office` の Collection Type スキーマ定義。API 経由で管理するフィールドとリレーションの制約を定義します。主な属性: name, slug, address, tel, business_hours, map_embed_url, service_areas。
