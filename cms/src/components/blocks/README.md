# blocks ディレクトリ README

## ディレクトリの役割
Dynamic Zone でページ本文を構成する block component 定義です。

## 配下ファイルと役割
- `cta-banner.json`: `cta-banner` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, body, cta です。
- `download-cta.json`: `download-cta` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, body, lead_magnet です。
- `faq-section.json`: `faq-section` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, items です。
- `image-text.json`: `image-text` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, body, image, image_position です。
- `office-info.json`: `office-info` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, office です。
- `quote.json`: `quote` component 定義。入力 UI と JSON 構造を規定し、主な属性は quote, author_name です。
- `related-case-studies.json`: `related-case-studies` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading です。
- `related-posts.json`: `related-posts` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading です。
- `rich-text.json`: `rich-text` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, body です。
- `stats-section.json`: `stats-section` component 定義。入力 UI と JSON 構造を規定し、主な属性は heading, stats です。

## 運用メモ
- 新しいファイルを追加したら、この README の「配下ファイルと役割」を更新してください。
